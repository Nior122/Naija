# Prototype Asset Notes

Stage 1 uses procedural shapes and colors drawn by the game's GDScript. It adds no third-party images, music, sound effects, fonts, map tiles, or copied game assets. Text uses Godot's built-in theme/font resources distributed with the engine.

For future asset additions:

- Prefer original work, public-domain/CC0 assets, or licenses compatible with the game's intended distribution.
- Record the asset name, source/creator, license, required attribution, modifications, and included file path here (or in a linked asset register) before committing it.
- Do not use assets extracted from other games or media without explicit permission.
- Keep large/generated geography and build outputs out of Git unless a deliberate content decision approves them.
