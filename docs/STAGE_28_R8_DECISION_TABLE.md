# Stage 28 Task 4: R8 Decision Table (D6–D12)

Status: **Decision table only. R8 is not implemented.** Source: `docs/STAGE_28_R8_RECOVERY_DESIGN.md` section 11.9
and the supporting text in sections 11.2–11.6. Stage 28 remains OPEN.

Key-only recovery stays in place. Nothing here removes it. Any change to it requires a tested replacement and a
migration plan (directive).

The columns "client release", "schema or account changes", and "deferrable" are assessments from the design text.
They have not been verified against the client code, because no recovery client code exists.

## Notes

- **Notice failure rule (adopted, section 11.9).** If the notice cannot be accepted, recovery does not start and no
  silent approval occurs. This is the strict rule of section 10.3 (D4). This table does not change it.
- **Order of decisions.** D8 and D12 block D6 implementation. D9 and D10 block operator recovery. D7 depends on D6
  and on a measured enrolment coverage. D11 must precede any channel launch.
- **No implementation is authorised by this table.** Section 11.8 lists the tests required before implementation.
- **Not claimed:** that email delivery works; that any provider is configured; that the legal review has happened.
